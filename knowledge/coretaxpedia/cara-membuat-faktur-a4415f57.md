## Cara membuat faktur

Terakhir diupdate pada:
17 Sep 2025

**Q: Bagaimana cara membuat faktur pajak di Coretax DJP?**

A: Cara membuat faktur pajak adalah sebagai berikut:

1. *Login* ke akun Coretax DJP menggunakan akun pihak yang ditunjuk sebagai *drafter* atau *signer*.
2. Masuk pada menu **e-Faktur** kemudian pilih **Pajak Keluaran**.

**Skema** ***Key In***

1. Klik **Buat Faktur** dan lengkapi formulir sesuai data transaksi yang dilakukan mencakup dokumen transaksi, informasi pembeli, dan detail transaksi.
2. Setelah detil transaksi muncul di tabel, kemudian klik **Simpan**.
3. Apabila sudah selesai melakukan input data faktur, langkah selanjutnya adalah melakukan **Upload Faktur**.

**Skema** ***Upload*** **XML**

1. Untuk membuat faktur dengan skema *upload* XML, pada layar "Pajak Keluaran", klik tombol **Impor Data**.
2. Unggah file XML yang telah disiapkan sesuai *template* dari DJP.
3. Sistem akan memproses file untuk pembuatan faktur pajak.
4. Apabila sudah selesai melakukan *upload* data faktur, langkah selanjutnya adalah melakukan **Upload Faktur**.

**Upload Faktur**

1. Pilih penyedia penandatangan serta isi tanda tangan digital berupa ID dan kata sandi untuk validasi akhir pembuatan faktur.
2. Klik tombol **Simpan** kemudian **Konfirmasi Tanda Tangan**.
3. Selesai.

# e-Faktur, Faktur Pajak, XML, Approval, dan Pajak Masukan

## Tiga skema pembuatan

FAQ resmi menyebut tiga skema umum:

1. Input manual/**key in**.
2. Unggah file XML secara massal.
3. Melalui PJAP yang terhubung dengan Coretax DJP.

Rujukan: [Skema umum pembuatan e-Faktur](https://www.pajak.go.id/coretaxpedia/skema-umum-pembuatan-efaktur).

## Key in dan upload XML

### Key in

1. Login dengan pihak yang ditunjuk sebagai **drafter** atau **signer**.
2. Buka **e-Faktur > Pajak Keluaran**.
3. Klik **Buat Faktur**.
4. Isi dokumen transaksi, identitas pembeli, dan detail transaksi.
5. Simpan, lalu lanjutkan ke **Upload Faktur**.

### XML

1. Dari **Pajak Keluaran**, klik **Impor Data**.
2. Unggah XML sesuai template DJP.
3. Tunggu pemrosesan sistem.
4. Lanjutkan ke **Upload Faktur**.

### Penandatanganan

Pilih penyedia penandatangan, isi ID dan kata sandi sesuai layar, klik **Simpan**, lalu **Konfirmasi Tanda Tangan**. Agent tidak boleh meminta nilai kredensial tersebut.

Rujukan: [Cara membuat faktur](https://www.pajak.go.id/coretaxpedia/cara-membuat-faktur).

## Intent faktur yang sering tertukar

- **Approval faktur** → [Approval faktur pajak](https://www.pajak.go.id/coretaxpedia/approval-faktur-pajak).
- **Nomor seri** → [Nomor seri faktur pajak](https://www.pajak.go.id/coretaxpedia/nomor-seri-faktur-pajak).
- **Pajak masukan tidak muncul** → [Faktur pajak masukan tidak ditemukan](https://www.pajak.go.id/coretaxpedia/faktur-pajak-masukan-tidak-ditemukan) dan FAQ kredit pajak masukan.
- **Tanggal mundur** → [Faktur tanggal mundur](https://www.pajak.go.id/coretaxpedia/faktur-tanggal-mundur); jangan memberi keputusan legal di luar isi sumber.
- **Uang muka/pelunasan** → [Faktur pajak uang muka dan pelunasan](https://www.pajak.go.id/coretaxpedia/faktur-pajak-uang-muka-dan-pelunasan).
- **Retur** → [Retur barang](https://www.pajak.go.id/coretaxpedia/retur-barang).
- **Digunggung** → [Identitas pembeli faktur pajak digunggung](https://www.pajak.go.id/coretaxpedia/identitas-pembeli-faktur-pajak-digunggung) dan [XML transaksi digunggung](https://www.pajak.go.id/coretaxpedia/xml-transaksi-digunggung).
- **NITKU pembeli/penjual** → [Pencantuman NITKU pada faktur pajak](https://www.pajak.go.id/coretaxpedia/pencantuman-nitku-pada-faktur-pajak).

## Data dan akses

Jika menu faktur tidak tersedia, ambil konteks role/PIC/impersonate dan permissions. Jika faktur atau pajak masukan tertentu tidak muncul, jangan meminta nomor faktur lengkap di chat; minta gejala umum dan eskalasi bila perlu.

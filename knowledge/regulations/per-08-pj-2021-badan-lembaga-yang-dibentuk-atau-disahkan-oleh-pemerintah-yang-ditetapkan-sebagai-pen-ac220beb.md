dibentuk atau disahkan oleh Pemerintah. | | | | | | | | | (4) | Badan/lembaga selain sebagaimana dimaksud pada ayat (2) dapat ditetapkan sebagai badan/lembaga penerima zakat atau sumbangan keagamaan

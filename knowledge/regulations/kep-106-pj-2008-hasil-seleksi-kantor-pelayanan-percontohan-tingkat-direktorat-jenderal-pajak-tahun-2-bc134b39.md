TENTANG

HASIL SELEKSI KANTOR PELAYANAN PERCONTOHAN
TINGKAT DIREKTORAT JENDERAL PAJAK TAHUN 2008

DIREKTUR JENDERAL PAJAK,

| Menimbang | : | a. | bahwa sejalan dengan perkembangan kebijaksanaan pemerintah dalam rangka perbaikan mutu pelayanan kepada masyarakat, perlu segera menetapkan langkah-langkah nyata untuk melaksanakan tugas tersebut; | |
| | | b. | bahwa berdasarkan Profile Kantor yang disampaikan oleh tiap-tiap Kantor Wilayah DJP, telah dilakukan seleksi oleh Bagian Organta dan Bagian Umum Sekretariat Direktorat Jenderal Pajak untuk memilih Kantor Pelayanan Percontohan Tingkat Direktorat Jenderal Pajak tahun 2008; | |
| | | c. | bahwa berdasarkan hasil seleksi sebagaimana dimaksud pada huruf b, dipandang perlu menetapkan pemenangnya dengan Keputusan Direktur Jenderal Pajak; | |
| Mengingat | : | 1. | Instruksi Presiden Nomor 1 Tahun 1995 tentang Perbaikan dan Peningkatan Mutu Pelayanan Aparatur Pemerintah kepada Masyarakat; | |
| | | 2. | Peraturan Menteri Pendayagunaan Aparatur Negara Nomor PER/25/M.PAN/05/2006, tentang Pedoman Penilaian Kinerja Unit Pelayanan Publik; | |
| | | 3. | Peraturan Menteri Keuangan Nomor 131/PMK.01/2006, tentang Organisasi dan Tata Kerja Departemen Keuangan sebagaimana telah diubah dengan Peraturan Menteri Keuangan Nomor 54/PMK.01/2007; | |
| Memperhatikan | : | 1. | Surat Sekretaris Jenderal Departemen Keuangan RI Nomor S-267/SJ/2008 tanggal 14 April 2008 perihal Penilaian Kinerja Pelayanan Publik Departemen Keuangan Tahun 2008; | |
| | | 2. | Surat Edaran Sekretaris Direktorat Jenderal Pajak Nomor SE-06/PJ.01/2008 tanggal 25 April 2008 tentang Penyampaian Usulan Calon Kantor Pelayanan Percontohan Tingkat Direktorat Jenderal Pajak Tahun 2008; | |
| MEMUTUSKAN : | | | | |
| Menetapkan | : | KEPUTUSAN DIREKTUR JENDERAL PAJAK TENTANG HASIL SELEKSI KANTOR PELAYANAN PERCONTOHAN TINGKAT DIREKTORAT JENDERAL PAJAK TAHUN 2008. | | |
| PERTAMA | : | Menetapkan Kantor Pelayanan Pajak Pratama Jakarta Menteng Satu sebagai pemenang Pertama dan Kantor Pelayanan Pajak Madya Jakarta Selatan sebagai pemenang Kedua serta Kantor Pelayanan Pajak Pratama Bandung Tegallega sebagai pemenang Ketiga Seleksi Kantor Pelayanan Percontohan Tingkat Direktorat Jenderal Pajak Tahun 2008. | | |
| KEDUA | : | Mengajukan Kantor Pelayanan Pajak Pratama Jakarta Menteng Satu sebagai Wakil Direktorat Jenderal Pajak untuk mengikuti Seleksi Kantor Pelayanan Percontohan Tingkat Departemen Keuangan Tahun 2008. | | |
| KETIGA | : | Keputusan Direktur Jenderal Pajak ini mulai berlaku pada tanggal ditetapkan. | | |
| | | Salinan Keputusan Direktur Jenderal Pajak ini disampaikan kepada : | | |
| | | 1. Sekretaris Jenderal Departemen Keuangan; u.p. Kepala Biro Organisasi dan Tatalaksana Departemen Keuangan; 2. Para Kepala Kantor Wilayah DJP di seluruh Indonesia; 3. Para Kepala Bagian di lingkungan Sekretariat DJP. | | |

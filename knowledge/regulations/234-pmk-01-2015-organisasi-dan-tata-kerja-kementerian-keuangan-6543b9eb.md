| | | c. | bahwa berdasarkan pertimbangan sebagaimana dimaksud dalam huruf a dan huruf b, perlu menetapkan Peraturan Menteri Keuangan tentang Organisasi Dan Tata Kerja Kementerian Keuangan; | | | | | |

| Menimbang | : | a. | bahwa pandemi *Corona Virus Disease* 2019 merupakan bencana nasional yang mempengaruhistabilitas ekonomi dan produktivitas masyarakat sebagai pekerja maupun pelaku usaha sehingga perlu dilakukan upaya pengaturan pemberian insentif pajak untuk mendukung penanggulangan dampak *Corona Virus Disease* 2019; | | | | | | | | | | | |

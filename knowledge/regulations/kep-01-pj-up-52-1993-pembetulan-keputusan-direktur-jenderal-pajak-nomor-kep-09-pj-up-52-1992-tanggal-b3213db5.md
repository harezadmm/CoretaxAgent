| Menimbang : | | |
| a. | bahwa didalam Keputusan Direktur Jenderal Pajak Nomor : KEP-09/UP./UP.52/1992 tanggal 20 Agustus 1992 terdapat beberapa kekeliruan dan kesalahan dalam pengetikan, maka dipandang perlu untuk mengadakan perbaikan dan pembetulan; | |
| b. | bahwa perbaikan dan pembetulan tersebut perlu diatur dengan Keputusan Direktur Jenderal Pajak; | |

| 3. | Peraturan Pemerintah Nomor 3 Tahun 1980 tentang Pengangkatan Dalam Pangkat Pegawai Negeri Sipil (Lembaran Negara Tahun 1980 Nomor 6, Tambahan Lembaran Negara Nomor 3156); | |
| 4. | Peraturan Pemerintah Nomor 31 Tahun 1986 tentang Tatacara Pemeriksaan Dibidang Perpajakan (Lembaran Negara Tahun 1986 Nomor 46, Tambahan Lembaran Negara Nomor 3339); | |
| 5. | Keputusan Presiden Nomor 15 Tahun 1984 tentang Susunan Organisasi Departemen sebagaimana telah beberapa kali diubah terakhir dengan Keputusan Presiden Nomor 4 Tahun 1990; | |

| 1. | Keputusan Menteri Keuangan Nomor 516/KMK.01/1992 tanggal 21 Mei 1989 tentang Organisasi dan Tatakerja Direktorat Jenderal Pajak; | |
| 2. | Keputusan Menteri Keuangan Nomor : 868/KMK.01/UP.10/1991 tanggal 16 Agustus 1991 tentang Pendelegasian Wewenang untuk Mengangkat/Memindahkan/Membebaskan Sementara/Mengangkat Kembali dan Memberhentikan Dalam Jabatan Fungsional Ajun Pemeriksa Pajak dan Ajun Pemeriksa Pajak Madya kepada Direktur Jenderal Pajak dan Jabatan Fungsional Ajun Pemeriksa Pajak Muda Kebawah kepada Sekretaris Dit.

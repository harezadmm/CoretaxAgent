TENTANG

PENGANGKATAN ANGGOTA DEWAN DIREKTUR
PERUSAHAAN PENERBIT SURAT BERHARGA SYARIAH NEGARA INDONESIA

MENTERI KEUANGAN,

| Menimbang | : | bahwa untuk melaksanakan ketentuan Pasal 11 Peraturan Pemerintah Nomor 57 Tahun 2008 tentang Pendirian Perusahaan Penerbit Surat Berharga Syariah Negara Indonesia perlu menetapkan Keputusan Menteri Keuangan tentang Pengangkatan Anggota Dewan Direktur Perusahaan Penerbit Surat Berharga Syariah Negara Indonesia; | | | | | |
| Mengingat | : | 1. | Undang-Undang Nomor 19 Tahun 2008 tentang Surat Berharga Syariah Negara (Lembaran Negara Republik Indonesia Tahun 2008 Nomor 70, Tambahan Lembaran Negara Republik Indonesia Nomor 4852); | | | | |
| | | 2. | Peraturan Pemerintah Nomor 56 Tahun 2008 tentang Perusahaan Penerbit Surat Berharga Syariah Negara (Lembaran Negara Republik Indonesia Tahun 2008 Nomor 117, Tambahan Lembaran Negara Republik Indonesia Nomor 4887); | | | | |
| | | 3. | Peraturan Pemerintah Nomor 57 Tahun 2008 tentang Pendirian Perusahaan Penerbit Surat Berharga Syariah Negara Indonesia (Lembaran Negara Republik Indonesia Tahun 2008 Nomor 118); | | | | |
| | | 4. | Keputusan Presiden Nomor 20/P Tahun 2005; | | | | |
| | | MEMUTUSKAN: | | | | | |
| Menetapkan | : | KEPUTUSAN MENTERI KEUANGAN TENTANG PENGANGKATAN ANGGOTA DEWAN DIREKTUR PERUSAHAAN PENERBIT SURAT BERHARGA SYARIAH NEGARA INDONESIA. | | | | | |
| PERTAMA | : | Mengangkat pejabat-pejabat tersebut di bawah ini untuk menjabat secara, *ex-officio* sebagai Direktur Utama dan anggota Dewan Direktur Perusahaan Penerbit SBSN Indonesia: | | | | | |
| | | 1. | Direktur Pembiayaan Syariah, Direktorat Jenderal Pengelolaan Utang - sebagai Direktur Utama merangkap anggota; | | | | |
| | | 2. | Direktur Surat Utang Negara, Direktorat Jenderal Pengelolaan Utang - sebagai anggota; | | | | |
| | | 3. | Direktur Penilaian Kekayaan Negara, Direktorat Jenderal Kekayaan Negara - sebagai anggota. | | | | |
| KEDUA | : | Direktur Utama dan anggota Dewan Direktur memiliki tugas dan wewenang sebagaimana dimaksud dalam Peraturan Pemerintah Nomor 57 Tahun 2008 tentang Pendirian Perusahaan Penerbit Surat Berharga Syariah Negara Indonesia. | | | | | |
| KETIGA | : | Direktur Utama dan anggota Dewan Direktur wajib tunduk dan melaksanakan ketentuan perundang-undangan yang berlaku di bidang Surat Berharga Syariah Negara. | | | | | |
| KEEMPAT | : | Masa kerja Dewan Direktur Perusahaan Penerbit Surat Berharga Syariah Negara Indonesia terhitung mulai dari ditetapkannya Keputusan Menteri Keuangan ini, sampai dengan dibubarkannya Perusahaan Penerbit Surat Berharga Syariah Negara Indonesia. | | | | | |
| KELIMA | : | Keputusan Menteri Keuangan ini mulai berlaku sejak tanggal ditetapkan, dengan ketentuan bahwa apabila di kemudian hari ternyata terdapat kekeliruan akan diadakan perbaikan sebagaimana mestinya. | | | | | |
| | | Salinan Keputusan Menteri Keuangan ini disampaikan kepada Yth: | | | | | |
| | | 1. | Sekretaris Jenderal; | | | | |
| | | 2. | Direktur Jenderal Pengelolaan Utang; | | | | |
| | | 3. | Direktur Jenderal Kekayaan Negara; | | | | |
| | | 4. | Direktur Jenderal Anggaran; | | | | |
| | | 5. | Direktur Jenderal Perbendaharaan; | | | | |
| | | 6. | Direktur Jenderal Pajak; | | | | |
| | | 7. | Kepala Badan Kebijakan Fiskal. | | | | |
| | | Petikan Keputusan ini disampaikan kepada yang berkepentingan untuk diketahui dan diindahkan. | | | | | |

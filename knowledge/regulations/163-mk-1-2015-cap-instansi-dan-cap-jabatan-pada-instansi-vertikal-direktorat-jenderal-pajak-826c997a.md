| | | | b. | bahwa berdasarkan pertimbangan sebagaimana dimaksud dalam huruf a, perlu menetapkan Keputusan Menteri Keuangan tentang Cap Instansi dan Cap Jabatan Pada Instansi Vertikal Direktorat Jenderal Pajak; | | |

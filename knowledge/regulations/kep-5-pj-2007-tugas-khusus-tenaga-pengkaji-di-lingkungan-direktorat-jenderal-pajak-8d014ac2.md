| DEPARTEMEN KEUANGAN REPUBLIK INDONESIA DIREKTORAT JENDERAL PAJAK | | | |
| KEPUTUSAN DIREKTUR JENDERAL PAJAK | | | |
| NOMOR KEP-5/PJ/2007 | | | |
| TENTANG | | | |
| TUGAS KHUSUS TENAGA PENGKAJI DI LINGKUNGAN DIREKTORAT JENDERAL PAJAK | | | |
| DIREKTUR JENDERAL PAJAK, | | | |
| Menimbang | : | a. | bahwa dalam rangka untuk menjamin kualitas kebijakan administrasi Direktorat Jenderal Pajak, telah dibentuk Tenaga Pengkaji di lingkungan Direktorat Jenderal Pajak dengan tugas meningkatkan kualitas telaahan dalam rangka pemecahan konsepsional secara keahlian di bidang perpajakan mengenai ekstensifikasi dan intensifikasi pajak, pengawasan dan penegakan hukum perpajakan, pembinaan dan penertiban sumber daya manusia, dan pelayanan perpajakan; |
| | | b. | bahwa sebagaimana diatur dalam Pasal 2 Keputusan Menteri Keuangan Nomor 218/KMK.01/2003 tentang Tenaga Pengkaji di Lingkungan Direktorat Jenderal Pajak, masih memberikan ruang untuk upaya dukungan telaahan profesional; |
| | | c. | bahwa kebutuhan telaahan profesional saat ini perlu difokuskan pada kajian Undang-Undang Perpajakan dan kajian yang berkaitan dengan Upaya *extra effort* agar kebijakan administrasi perpajakan lebih tajam; |
| | | d. | bahwa luasnya cakupan tugas menyebabkan tugas khusus dalam butir c diatas, perlu didistribusikan kepada seluruh Tenaga Pengkaji di lingkungan Direktorat Jenderal Pajak; |
| | | e. | bahwa berdasarkan pertimbangan sebagaimana dimaksud dalam butir b sampai dengan butir d di atas, perlu ditetapkan Keputusan Direktur Jenderal Pajak tentang Tugas Khusus Tenaga Pengkaji di Lingkungan Direktorat Jenderal Pajak; |
| Mengingat | : | 1. | Peraturan Presiden Nomor 9 Tahun 2005 tentang Kedudukan, Tugas, Fungsi, Susunan Organisasi, dan Tata Kerja Kementerian Negara Republik Indonesia sebagaimana telah diubah terakhir dengan Peraturan Presiden nomor 94 tahun 2006; |
| | | 2. | Peraturan Presiden Nomor 10 Tahun 2005 tentang Unit Organisasi dan Tugas Eselon I Kementerian Negara Republik Indonesia sebagaimana telah diubah terakhir dengan Peraturan Presiden Nomor 66 Tahun 2006; |
| | | 3. | Keputusan Menteri Keuangan Nomor 218/KMK.01/2003 tentang Tenaga Pengkaji di Lingkungan Direktorat Jenderal Pajak; |
| | | 4. | Peraturan Menteri Keuangan Nomor 131/PMK.01/2006 tentang Organisasi dan Tata Kerja Departemen Keuangan; |
| MEMUTUSKAN : | | | |
| Menetapkan | : | KEPUTUSAN DIREKTUR JENDERAL PAJAK TENTANG TUGAS KHUSUS TENAGA PENGKAJI DI LINGKUNGAN DIREKTORAT JENDERAL PAJAK. | |
| PERTAMA | : | Memberikan tugas khusus kepada para Tenaga Pengkaji dalam rangka optimalisasi efektifitas kinerja Direktorat Jenderal Pajak sebagaimana tercantum dalam Keputusan Direktorat Jenderal Pajak ini. | |
| KEDUA | : | Tugas khusus Tenaga Pengkaji Bidang Ekstensifikasi dan Intensifikasi Pajak : | |
| | | a. | Melakukan kajian terhadap ketentuan Pajak Penghasilan; |
| | | b. | Hasil kajian tersebut dituangkan dalam bentuk analisis dan rekomendasi yang dipandang perlu bagi Direktorat Jenderal Pajak untuk melakukan penyempurnaan baik dari segi ketentuan maupun administrasi; |
| | | c. | Memberikan rekomendasi saran tidak sehubungan dengan *follow up* hasil kajian setelah terlebih dahulu dilakukan koordinasi dengan Tenaga Pengkaji lainnya berupa tahapan yang harus dilakukan agar penyesuaian ketentuan dan atau administrasi perpajakan dapat dilaksanakan dengan efektif; |
| | | d. | Melakukan pemantauan kinerja *extra effort* untuk kantor-kantor di wilayah Kalimantan dan sulawesi; |
| | | e. | Memberikan laporan hasil pemantauan yang memuat rekomendasi hal-hal penting untuk optimalisasi *extra effort*. |
| KETIGA | : | Tugas Khusus Tenaga Pengkaji Bidang Pelayanan Perpajakan : | |
| | | a. | Melakukan kajian terhadap ketentuan Pajak Pertambahan Nilai; |
| | | b. | Hasil kajian tersebut dituangkan dalam bentuk analisis dan rekomendasi yang dipandang perlu bagi Direktorat Jenderal Pajak untuk melakukan penyempurnaan baik dari segi ketentuan maupun administrasi; |
| | | c. | Memberikan rekomendasi saran tidak sehubungan dengan *follow up* hasil kajian setelah terlebih dahulu dilakukan koordinasi dengan Tenaga Pengkaji lainnya berupa tahapan yang harus dilakukan agar penyesuaian ketentuan dan atau administrasi perpajakannya dapat dilaksanakan dengan efektif; |
| | | d. | Melakukan pemantauan kinerja extra effort untuk kantor-kantor di wilayah Jawa; |
| | | e. | Memberikan laporan hasil pemantauan yang memuat rekomendasi tentang hal-hal penting untuk optimalisasi *extra effort*. |
| KEEMPAT | : | Tugas Khusus Tenaga Pengkaji Bidang Pembinaan dan Penertiban SDM : | |
| | | a. | Melakukan kajian terhadap ketentuan PBB dan BPHTB; |
| | | b. | Melakukan kajian untuk optimalisasi kinerja penilaian dan pendataan; |
| | | c. | Hasil kajian tersebut dituangkan dalam bentuk analisis dan rekomendasi yang dipandang perlu bagi Direktorat Jenderal Pajak untuk melakukan penyempurnaan baik dari segi ketentuan maupun administrasi; |
| | | d. | Memberikan rekomendasi saran tindak sehubungan dengan *follow up* hasil kajian setelah terlebih dahulu dilakukan koordinasi dengan Tenaga Pengkaji lainnya berupa tahapan yang harus dilakukan agar penyesuaian ketentuan dan atau administrasi perpajakannya dapat dilaksanakan dengan efektif; |
| | | e. | Melakukan pemantauan kinerja *extra effort* untuk kantor-kantor di wilayah Indonesia Timur; |
| | | f. | Memberikan laporan hasil pemantauan yang memuat rekomendasi tentang hal-hal penting untuk optimalisasi *extra effort*. |
| KELIMA | : | Tugas Khusus Tenaga Pengkaji Bidang Pengawasan dan Penegakan Hukum Pajak : | |
| | | a. | Melakukan kajian terhadap Ketentuan Umum dan Tata Cara Perpajakan baik yang lama maupun yang baru; |
| | | b. | Hasil kajian tersebut dituangkan dalam bentuk analisis dan rekomendasi yang dipandang perlu bagi Direktorat Jenderal Pajak untuk melakukan penyempurnaan baik dari segi ketentuan maupun administrasi; |
| | | c. | Memberikan rekomendasi saran tindak sehubungan dengan *follow up* hasil kajian setelah terlebih dahulu dilakukan koordinasi dengan Tenaga Pengkaji lainnya berupa tahapan yang harus dilakukan agar penyesuaian ketentuan dan atau administrasi perpajakannya dapat dilaksanakan dengan efektif; |
| KEENAM | : | Keputusan Direktur Jenderal Pajak ini mulai berlaku pada tanggal ditetapkan. | |
| | | Salinan Keputusan Direktur Jenderal Pajak ini disampaikan kepada : | |
| | | 1. | Sekretaris Direktorat Jenderal Pajak; |
| | | 2. | Para Direktur di lingkungan Direktorat Jenderal Pajak; |
| | | 3. | Para Kepala Kantor Wilayah di lingkungan Direktorat Jenderal Pajak; |
| | | 4. | Para Tenaga Pengkaji di lingkungan Direktorat Jenderal Pajak. |

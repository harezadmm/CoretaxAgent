MENTERI KEUANGAN REPUBLIK INDONESIA,

| Menimbang | : | a. | bahwa telah ditandatangani *Memorandum of Understanding* (MoU) antara Pemerintah Indonesia dan Koninklije Nederlands Centrale Vereniging,tot Bestrijding der Tuberculosis (KNCV); | | |
| | | b. | bahwa rekomendasi dari Sekretariat Negara KNCV dapat ditetapkan sebagai Organisasi Internasional; | | |
| | | c. | bahwa berdasarkan pertimbangan sebagaimana dimaksud dalam huruf a dan b, perlu menetapkan Keputusan Menteri Keuangan tentang Perubahan Keempat Atas Keputusan Menteri Keuangan Nomor 89/KMK.04/2002 Tentang Tata Cara Pemberian Pembebasan Bea Masuk Dan Cukai Atas Impor Barang Untuk Keperluan Badan Internasional Beserta Para Pejabatnya Yang Bertugas Di Indonesia; | | |
